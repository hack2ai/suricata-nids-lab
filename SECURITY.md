# Security Policy

## Scope

This repository contains an educational Suricata NIDS lab intended for isolated, authorized cybersecurity training.

## Reporting security issues

Do not use this repository's lab configuration to access systems you do not own or have explicit permission to test.

For vulnerabilities in the repository itself, open a private GitHub security report when GitHub Security Advisories are enabled. Do not publish credentials, secrets, session cookies, private logs, or sensitive network data in a public issue.

## Lab safety

Intentionally vulnerable VMs such as Metasploitable and DVWA must remain isolated from normal networks and the public Internet.

The repository intentionally excludes VM images, runtime logs, packet captures, credentials, and secrets.
